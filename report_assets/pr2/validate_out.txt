Требования и действия при нарушении:
  D-01: все 21 исходный столбец и row_id, period; типы приводятся → порция не обрабатывается
  D-02: периоды порции позже последнего обработанного → порция не обрабатывается
  D-03: нет полных дубликатов (без row_id) → лишние копии удалены, предупреждение
  D-04: age 17–100, campaign ≥ 1, previous ≥ 0, pdays 0–999, duration ≥ 0 → записи исключены, предупреждение
  D-05: значения категориальных признаков из справочника → значение заменено на unknown, предупреждение
  D-06: доля unknown выросла не больше чем на 5 п. п. → предупреждение, проверка источника
  D-07: nonexistent ⇔ previous = 0; pdays ≠ 999 ⇒ previous > 0 → предупреждение, записи остаются
  D-08: доля записей с макропоказателями вне [min; max] исходной части ≤ 5 % по каждому → предупреждение: модель вне области обучения, требуется переобучение
  D-09: PSI age и campaign относительно исходной части не больше 0,2 → предупреждение о дрейфе
